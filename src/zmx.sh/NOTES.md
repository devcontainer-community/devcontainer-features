# zmx.sh

## Project

- [zmx](https://zmx.sh)

## Description

`zmx` persists terminal sessions so you can detach and reattach without stopping their processes. It preserves native terminal scrollback and leaves window management to your terminal or operating system.

## Installation Method

Downloaded as a pre-compiled binary from the [GitHub releases page](https://github.com/neurosnap/zmx/releases) and placed in `/usr/local/bin`.
